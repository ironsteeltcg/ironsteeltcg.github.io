How much is a Ascended Heroes master set?

An Ascended Heroes master set is 473 cards, $4,351.47 at today's prices (TCGPlayer market prices via TCGCSV as of October 15, 2026): base (main set 1–217) 217 cards $80.64, reverse holos 178 cards $52.66, secret rares 78 cards $4,218.17.

A master set is one copy of every card in the set, including the secret rares numbered past the printed set size, plus the reverse holo version of every card that has one. In Scarlet & Violet and Mega Evolution sets the ex, Ultra Rare and other higher-rarity cards don't come in reverse holo, so the reverse holo count (178) is lower than the main set count (217). Our master set price is the full set plus every reverse holo, at TCGPlayer market prices via TCGCSV. Some collectors also count promos or stamped versions. We don't include them.

Ascended Heroes FAQ

How much does it cost to complete Ascended Heroes?

About $4,298.81 for one copy of all 295 cards at TCGPlayer market prices. The main set (cards 1–217) is about $80.64. A master set with all 178 reverse holos is about $4,351.47.

How many cards are in Ascended Heroes?

Ascended Heroes has 295 cards: 217 in the main set (numbered 1–217) plus 78 numbered above 217.

What is the most expensive card in Ascended Heroes?

The most expensive Ascended Heroes card is Mega Gengar ex (#284, Special Illustration Rare) at about $816.38 market price.

How much does it cost to master set Ascended Heroes?

473 cards, about $4,351.47 at today's prices (TCGPlayer market prices via TCGCSV as of October 15, 2026): base (main set 1–217) 217 cards $80.64, reverse holos 178 cards $52.66, secret rares 78 cards $4,218.17. Most of it is the 78 secret rares, which add $4,218.17.

How many cards are in a Ascended Heroes master set?

473: 217 main-set cards, 78 secret rares and 178 reverse holos. 39 main-set cards have no reverse holo.

What counts toward a Ascended Heroes master set?

Every card numbered in the set, including secret rares past #217, plus the reverse holo of every card that has one. Promos and stamped versions aren't included in our total.

What's the cheapest way to master set Ascended Heroes?

Buy singles. The 217-card main set is about $80.64 and all 178 reverse holos about $52.66, so $133.30 covers everything except the secret rares. Buy the chase cards last.
