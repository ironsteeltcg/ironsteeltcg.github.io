How much is a Scarlet & Violet Base Set master set?

A Scarlet & Violet Base Set master set is 444 cards, $746.73 at today's prices (TCGPlayer market prices via TCGCSV as of October 15, 2026): base (main set 1–198) 198 cards $35.69, reverse holos 186 cards $47.81, secret rares 60 cards $663.23.

A master set is one copy of every card in the set, including the secret rares numbered past the printed set size, plus the reverse holo version of every card that has one. In Scarlet & Violet and Mega Evolution sets the ex, Ultra Rare and other higher-rarity cards don't come in reverse holo, so the reverse holo count (186) is lower than the main set count (198). Our master set price is the full set plus every reverse holo, at TCGPlayer market prices via TCGCSV. Some collectors also count promos or stamped versions. We don't include them.

Scarlet & Violet Base Set FAQ

How much does it cost to complete Scarlet & Violet Base Set?

About $698.92 for one copy of all 258 cards at TCGPlayer market prices. The main set (cards 1–198) is about $35.69. A master set with all 186 reverse holos is about $746.73.

How many cards are in Scarlet & Violet Base Set?

Scarlet & Violet Base Set has 258 cards: 198 in the main set (numbered 1–198) plus 60 numbered above 198.

What is the most expensive card in Scarlet & Violet Base Set?

The most expensive Scarlet & Violet Base Set card is Gardevoir ex (#245, Special Illustration Rare) at about $68.32 market price.

How much does it cost to master set Scarlet & Violet Base Set?

444 cards, about $746.73 at today's prices (TCGPlayer market prices via TCGCSV as of October 15, 2026): base (main set 1–198) 198 cards $35.69, reverse holos 186 cards $47.81, secret rares 60 cards $663.23. Most of it is the 60 secret rares, which add $663.23.

How many cards are in a Scarlet & Violet Base Set master set?

444: 198 main-set cards, 60 secret rares and 186 reverse holos. 12 main-set cards have no reverse holo.

What counts toward a Scarlet & Violet Base Set master set?

Every card numbered in the set, including secret rares past #198, plus the reverse holo of every card that has one. Promos and stamped versions aren't included in our total.

What's the cheapest way to master set Scarlet & Violet Base Set?

Buy singles. The 198-card main set is about $35.69 and all 186 reverse holos about $47.81, so $83.50 covers everything except the secret rares. Buy the chase cards last.
