How much is a Paradox Rift master set?

A Paradox Rift master set is 428 cards, $1,174.82 at today's prices (TCGPlayer market prices via TCGCSV as of October 15, 2026): base (main set 1–182) 182 cards $42.88, reverse holos 162 cards $36.42, secret rares 84 cards $1,095.52.

A master set is one copy of every card in the set, including the secret rares numbered past the printed set size, plus the reverse holo version of every card that has one. In Scarlet & Violet and Mega Evolution sets the ex, Ultra Rare and other higher-rarity cards don't come in reverse holo, so the reverse holo count (162) is lower than the main set count (182). Our master set price is the full set plus every reverse holo, at TCGPlayer market prices via TCGCSV. Some collectors also count promos or stamped versions. We don't include them.

Paradox Rift FAQ

How much does it cost to complete Paradox Rift?

About $1,138.40 for one copy of all 266 cards at TCGPlayer market prices. The main set (cards 1–182) is about $42.88. A master set with all 162 reverse holos is about $1,174.82.

How many cards are in Paradox Rift?

Paradox Rift has 266 cards: 182 in the main set (numbered 1–182) plus 84 numbered above 182.

What is the most expensive card in Paradox Rift?

The most expensive Paradox Rift card is Groudon (#199, Illustration Rare) at about $103.61 market price.

How much does it cost to master set Paradox Rift?

428 cards, about $1,174.82 at today's prices (TCGPlayer market prices via TCGCSV as of October 15, 2026): base (main set 1–182) 182 cards $42.88, reverse holos 162 cards $36.42, secret rares 84 cards $1,095.52. Most of it is the 84 secret rares, which add $1,095.52.

How many cards are in a Paradox Rift master set?

428: 182 main-set cards, 84 secret rares and 162 reverse holos. 20 main-set cards have no reverse holo.

What counts toward a Paradox Rift master set?

Every card numbered in the set, including secret rares past #182, plus the reverse holo of every card that has one. Promos and stamped versions aren't included in our total.

What's the cheapest way to master set Paradox Rift?

Buy singles. The 182-card main set is about $42.88 and all 162 reverse holos about $36.42, so $79.30 covers everything except the secret rares. Buy the chase cards last.
